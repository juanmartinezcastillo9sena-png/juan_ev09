# TaskFlow – Panel de actividades y tareas

Mini proyecto Front-End (AA3-EV09 · Alternativa 3) – SENA, Tecnólogo en Análisis y Desarrollo de Software.

## Funcionalidades
- Resumen con total, pendientes, en proceso y completadas (se actualiza automáticamente).
- Registro de actividades con validación en JavaScript.
- Listado en tabla (tarjetas en celular) con cambio de estado: Pendiente → En proceso → Completada.
- Filtros por estado y prioridad.
- Eliminación con confirmación.

## Tecnologías
HTML5 · CSS3 (Flexbox y Grid, responsive) · JavaScript básico. Sin frameworks ni base de datos.

## Estructura
```

├── index.html
```
